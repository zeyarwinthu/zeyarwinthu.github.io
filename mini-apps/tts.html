Type English text, pick a voice, then play it back or record it to a downloadable audio file. Runs entirely in your browser — no account, no API key.

Tip: "Play" previews instantly. "Download" records the audio while it speaks, so the saved WAV uses the same voice you previewed. When the share prompt appears, pick Entire Screen (or the window) and tick "Share system audio" — speech audio usually bypasses "tab audio", so screen + system audio is the reliable choice. Chrome or Edge on desktop.
